# Contributing to termless

Thank you for your interest! Ideas, bug reports and questions are very welcome; please open an issue. A clear description, or a small example that shows the problem, helps most, and we aim to answer quickly.

This repo accepts direct pull requests from long-term collaborators only. For everyone else, we write each change ourselves from your description, and we credit you by name in the release notes. With AI-assisted development, building each change ourselves from a clear description is the safer and faster path for everyone.

Please describe the problem rather than pasting large pieces of code; short snippets that reproduce a bug are fine.
